Cara Memasang VPN KCI

Agar peta bisa dibuka dari luar kantor

VPN dipasang di Windows, bukan di aplikasi ini. Setelah tersambung, peta akan tampil sendiri di Dashboard.
  1. 1 Buka Settings → Network & Internet → VPN, lalu klik Add VPN.
  2. 2 VPN provider: Windows (built-in). Connection name: KCI.
  3. 3 Server name or address: vpn.kci.id · VPN type: Automatic.
  4. 4 Type of sign-in info: Username and password.
  5. 5 Isi username & password VPN. Minta ke admin unit bila belum punya — kredensial sengaja tidak dicantumkan di halaman ini.
  6. 6 Simpan, lalu klik Connect. Setelah tersambung, kembali ke Dashboard dan klik tombol muat ulang pada kartu peta.
