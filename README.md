# TTC — Train Traffic Simulator

TTC adalah alat bantu perencanaan operasi kereta api. Proyek ini sedang dibangun bertahap mengikuti `PROJECT.md`, `ROADMAP.md`, dan `STATE.md`.

## Posisi saat ini

Tahap aktif: **Tahap 0 — Fondasi Kendali**.

Aplikasi utama berada di folder `app/` dan menggunakan HTML + JavaScript murni tanpa server. Kode Python desktop v0.1 lama tetap disimpan di `referensi-python/` hanya sebagai referensi logika.

## Uji Tahap 0

Buka `app/index.html` di browser. Halaman harus menampilkan:

**TTC — Train Traffic Simulator**
