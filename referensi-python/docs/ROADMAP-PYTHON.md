# Roadmap TTC

## v0.1 — UI Shell
- Branding TTC penuh.
- Bahasa Indonesia.
- Menu, toolbar, panel, kanvas jaringan, log, status.
- Model data dasar.

## v0.2 — Project Editor
- Format proyek `.ttc`.
- Editor stasiun, jalur, sinyal, wesel.
- Simpan/buka proyek.

## v0.3 — Jadwal & Diagram
- Data nomor KA dan relasi.
- Waktu datang/berangkat.
- Import CSV/Excel.
- Diagram perjalanan waktu–jarak.

## v0.4 — Engine Dasar
- Waktu tempuh dan dwell.
- Headway minimum.
- Deteksi konflik blok/peron.
- Short turn dan turnaround.

## v0.5 — Simulasi Operasi
- Discrete-event simulation.
- Sinyal/blok.
- Propagasi keterlambatan.
- Evaluasi kapasitas dan kinerja.
