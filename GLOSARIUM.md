# GLOSARIUM.md — Istilah Wajib untuk AI

> AI wajib memakai istilah ini dengan arti di bawah. Dilarang mengarang padanan sendiri.

| Istilah | Arti dalam proyek ini |
|---|---|
| **GAPEKA** | Grafik Perjalanan Kereta Api. Grafik dua sumbu: mendatar = waktu, tegak = stasiun berskala jarak. Tiap kereta digambar sebagai garis miring. |
| **Daftar Waktu** | Tabel jam datang & berangkat tiap KA di tiap stasiun. Bentuk tabel dari GAPEKA. |
| **Petak Jalan** | Ruas lintas antara dua stasiun yang berdampingan. |
| **Petak Blok** | Bagian petak jalan yang dibatasi sinyal; hanya boleh diisi satu KA. |
| **Lintas Tunggal** | Satu jalur dipakai dua arah. Kereta berlawanan arah harus bersilang di stasiun. |
| **Lintas Ganda** | Dua jalur, masing-masing satu arah. |
| **Persilangan** | Dua KA berlawanan arah bertemu di stasiun pada lintas tunggal. |
| **Penyusulan** | KA cepat mendahului KA lambat di stasiun. |
| **Headway** | Selang waktu minimum antara dua KA searah. |
| **Waktu Tempuh** | Lama perjalanan KA pada satu petak jalan. |
| **WT (Waktu Tambahan)** | Waktu cadangan yang disisipkan pada petak agar jadwal tahan gangguan. |
| **Dwell / Waktu Berhenti** | Lama KA berhenti di stasiun untuk naik-turun penumpang. |
| **Relasi** | Pasangan stasiun awal–akhir sebuah perjalanan (mis. Bogor–Jakarta Kota). |
| **Nomor KA** | Identitas perjalanan. Ganjil/genap biasanya menandakan arah. |
| **Hilir / Hulu** | Arah perjalanan. Dibedakan warna garis di GAPEKA. |
| **TS (Trainset)** | Satu rangkaian kereta utuh. |
| **Putaran / Dinasan** | Rangkaian perjalanan berurutan yang dikerjakan satu TS dalam sehari. |
| **Okupansi Jalur** | Jumlah KA yang menempati jalur stasiun pada saat bersamaan. Tidak boleh melebihi jumlah jalur. |
| **Emplasemen** | Susunan jalur di stasiun. |
