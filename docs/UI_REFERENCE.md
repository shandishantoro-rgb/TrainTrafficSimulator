# Referensi UI TTC

Referensi visual yang disepakati sebelumnya:
- Judul: `TTC – Train Traffic Simulator`.
- Bahasa utama: Bahasa Indonesia.
- Menu: Berkas, Edit, Tampilan, Simulasi, Jadwal, Infrastruktur, Kereta, Alat, Jendela, Bantuan.
- Panel kiri: Proyek dan Properti.
- Tengah: Peta Jalur / Diagram Perjalanan.
- Panel kanan: Daftar Kereta, Informasi Kereta, Opsi Tampilan.
- Bawah: Log Simulasi dan status bar.
- Palet: navy, merah, putih, abu-abu; kanvas jaringan gelap.

UI v0.1 mengimplementasikan struktur tersebut sebagai aplikasi Qt nyata.
